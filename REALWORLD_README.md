# Real-world resolution intelligence — public SDK corpus
A bounded, explicitly opted-in public upstream qualification. Use the existing self-service package, Linux x86-64, Python, Node/npm and bubblewrap. No credentials, model API, live service, arbitrary issue code or automated publication.

    ./tredven-assurance --workspace ./new-private-state init
    ./tredven-assurance --workspace ./new-private-state corpus --allow-public-acquisition

The curated corpus is ten distinct public issue probes, not a crawler of all MCP servers. The runner uses a fixed official npm SDK identity and selected stable versions with fixed Zod 3/4 versions, plus the current verified v1 latest tag from the official registry. It obtains a lockfile, checks public HTTPS registry destinations and SHA-512 integrity fields, installs with lifecycle scripts disabled, and executes the authored probe under bubblewrap with external network unshared, no mounted host home and read-only staged project. The lockfiles, source hash, runtime hash, observed results, and native Rust decisions are retained. This is a controlled trusted-upstream local laboratory, not a hardened multi-tenant service for arbitrary untrusted packages. Lockfile resolution can change between runs; retain exact lockfiles for independent repetition. The installer uses npm outside the runtime sandbox with a clean environment; the public scope must be authorized. No general supply-chain authenticity or security guarantee follows from SRI.

Output: public-corpus/report.json (private evidence), report.html (reviewable public-data report), observations.json, per-profile lockfiles, attempt.json. Use a new workspace per run. CI exit 0 means the requested matrix was observed, not that all cases passed; exit 2 means at least one observation incomplete. The report selects only a tested same-Zod non-older SDK alternative, or if none, a tested alternative Zod on the same SDK. Such an alternative is scoped to that issue; it is not a recommendation to downgrade a dependency or upgrade a live host. Other probe failures can coexist. No automatic deployment. Reports are not independently signed.

No live HY4 or Hermes evidence.

Human time savings, broad agent/client coverage and external demand are unmeasured. Public report review and release require separate authorization.
