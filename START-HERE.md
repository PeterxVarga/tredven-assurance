# Tredven Assurance — source of the local preview

Read MARKET_README.md for scope, reference catalogue, lookup and reproducibility. The source checkout contains the Python and JavaScript implementation, exact npm locks, public reference evidence and static site. For the quickest verified install, use the Linux x86-64 binary distribution in the release assets. This source-only export intentionally omits the pinned Rust executable and binary distribution checksum manifest. The Rust core's matching public source is in the accompanying source archive, or at https://github.com/PeterxVarga/tredven-upstream/tree/1c8a15ad84858bead99b88e655915975ceefb2e9 . Independently built binaries must be qualified and the pin updated; byte-for-byte reproducible core builds have not been established. No automatic updates, live deployment, telemetry or hosted service. Historical reference locks may contain known vulnerabilities; they are laboratory data, not recommended dependencies.
