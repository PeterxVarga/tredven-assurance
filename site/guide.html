TREDVEN / ASSURANCEQuickstart

Get started locally

Linux x86-64, Python 3.11+, Node 22.19+, npm, bubblewrap with unprivileged namespaces. Review the archive and SHA-256 before running.

Install and discover

./install.sh
./tredven-assurance --workspace ./state init
./tredven-assurance --workspace ./state discover

Reproduce the public SDK corpus

./tredven-assurance --workspace ./state corpus --allow-public-acquisition

Inspect a tested combination

./tredven-assurance --workspace ./state lookup --catalog ./catalog.json --sdk 1.25.0 --zod 3.25.76 --requires 1302

Use the included README for disposable stdio projects. No arbitrary public code, OAuth, remote MCP or production changes. A package release is not yet public.
